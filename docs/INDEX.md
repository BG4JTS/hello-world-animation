## 🎉 使用建议

### 第一次使用

1. 阅读 **QUICKSTART.md**（3分钟）
2. 运行 `npm run dev`（实时预览）
3. 参考 **TOOLS_GUIDE.md** 了解所有命令
4. 开始开发！

### 日常开发

1. 写代码
2. `npm run dev` 实时预览
3. `npm run validate` 验证
4. `npm run render` 渲染
5. `npm run play` 查看

### 遇到问题

1. 查看 **DEBUGGING_GUIDE.md**
2. 运行 `npm run validate`
3. 参考 **BEST_PRACTICES.md**
4. 在预览中调试 `npm run dev`
