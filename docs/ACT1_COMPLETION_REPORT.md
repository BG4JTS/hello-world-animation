## 🐛 已修复的问题

### 问题1: 字符位置跟随光标移动
**症状**：'a', 'asdf', 'wasd' 等字符随着光标飞来飞去

**原因**：
```tsx
// 错误代码
<ASCIIText text="a" x={cursorX - 30} y={cursorY} />
```

**修复**：
```tsx
// 修复后：使用固定坐标
<ASCIIText text="a" x={930} y={540} />
```

### 问题2: 光标初始延迟
**症状**：前3秒画面是黑屏，光标从frame 180才出现

**原因**：
```tsx
{frame >= 180 && <Cursor ... />}
```

**修复**：
```tsx
// 光标从frame 0就存在
<Cursor x={cursorX} y={cursorY} ... />
```

### 问题3: 终端展开延迟
**症状**：终端在720帧出现但820帧才展开，有100帧延迟

**原因**：
```tsx
<Terminal startFrame={820} expandDuration={24} />
```

**修复**：
```tsx
<Terminal startFrame={720} expandDuration={60} />
```

### 问题4: 动画路径不连贯
**症状**：光标移动突兀，跳跃轨迹不自然

**修复**：完全重写了`getCursorPosition()`函数，分为8个清晰的阶段

### 问题5: ASCIIText的delay参数使用错误
**症状**：渲染在frame 301时崩溃

**原因**：`delay={0}`导致插值计算异常

**修复**：使用正确的delay值匹配元素出现的帧数

## 💡 经验总结

### 成功的关键

1. ✅ **先预览，后渲染**
   - 渲染要2-3分钟
   - 预览只需< 1秒
   - 问题发现快100倍

2. ✅ **固定 vs 动态位置**
   - 场景道具（文字）用固定坐标
   - 角色（光标）用动态计算
   - 绝不混用

3. ✅ **明确的时间线常量**
   - 所有关键帧用常量定义
   - 一眼看懂故事结构
   - 调整时间只改一处

4. ✅ **分阶段开发**
   - 先做5秒，确认正确
   - 再扩展到10秒、15秒
   - 不要一次写完20秒

5. ✅ **调试信息永远开着**
   - 显示当前帧数
   - 显示当前阶段
   - 显示关键位置
   - 开发完成前不删除
